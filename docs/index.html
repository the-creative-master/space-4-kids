About Space for Kids

No AI fluff. Every fact was written and checked against NASA, ESA, and JPL data (2024). Textures are procedurally drawn — no scraped images.

  • Built in TypeScript + Three.js — single canvas, 15k stars, instanced asteroid belt.
  • Planet sizes are kid-scale (exaggerated) so you can actually see Mercury vs Jupiter. Distances are compressed but proportional.
  • Orbits and rotations use real periods, sped up for observation.
  • “Beyond” distances are logarithmic — you’re seeing a map, not true emptiness. Real interstellar space is unimaginably emptier.

Made for curious kids (and adults who never stopped). If you spot a mistake, it’s a human one — tell us and we’ll fix it.

Typefaces: Space Grotesk & Outfit. Data sources: NASA Planetary Fact Sheets, JPL Small-Body Database, Gaia DR3.
