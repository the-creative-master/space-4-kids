About Space for Kids

No AI fluff — real 3D from GitHub. Planet textures fetched live from KyleGough/solar-system via GitHub API, spacecraft GLBs from nasa/NASA-3D-Resources (Voyager, Hubble, ISS, Apollo LM, Parker, MRO). Falls back to procedural canvas textures if offline.

  • Built in TypeScript + Three.js — single canvas, 15k stars, instanced asteroid belt, GLTFLoader + Draco. Dwarf planets + 6 asteroids included.
  • Kid Scale / True Scale toggle — see why real scale would be invisible; drag orbits to experiment.
  • Orbits and rotations use real periods, sped up for observation. Click Tour for cinematic fly-by, double-click planet to dock.
  • “Beyond” distances are logarithmic — you’re seeing a map, not true emptiness.
  • Spacecraft orbit their parents in real time — click ISS to inspect. All spacecraft now at 30% previous size.

Made for curious kids (and adults who never stopped). If you spot a mistake, it’s a human one — tell us and we’ll fix it.

Typefaces: Space Grotesk & Outfit. Data sources: NASA Planetary Fact Sheets, JPL Small-Body Database, Gaia DR3.
